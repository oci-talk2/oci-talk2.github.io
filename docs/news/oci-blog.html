2026-09-04 업데이트​

2026-09-03 업데이트​

  • Grafana 관측성을 갖춘 OKE에서 복제된 M3DB 클러스터 배포 — 이전 포스트에서 구축한 Btrfs 기반 스토리지를 기반으로, OKE 클러스터에 M3DB 복제 클러스터를 설치하고 Grafana 대시보드로 모니터링을 연결했습니다. 복제 설정을 통해 데이터 가용성을 높이고, Grafana를 통해 실시간 메트릭을 시각화합니다. 전체 배포 과정은 자동화된 워크플로로 제공됩니다.
  • OKE에서 Btrfs 기반 스토리지 구축: 수동 및 자동 방식 — 관측 워크로드의 지속적인 시계열 쓰기를 위해 OKE 클러스터에 Btrfs 파일시스템을 적용한 스토리지를 구축하는 방법을 소개합니다. 수동 방식은 볼륨 연결과 포맷을 직접 수행하고, 자동 방식은 Terraform·Ansible 스크립트를 이용해 동일한 구성을 반복 가능하게 구현합니다. 두 접근 모두 내구성과 예측 가능한 성능을 제공합니다.
  • OCI에서 PostgreSQL 보안 – 방어 심층 전략 — OCI Fully Managed PostgreSQL Service는 네트워크, 인프라, 데이터, 애플리케이션 계층에서 다중 보안 레이어를 적용합니다. 자동화된 패치 관리, 암호화된 백업, 세분화된 접근 제어 등을 통해 데이터베이스를 보호합니다. 이러한 방어 심층 접근 방식은 성능과 가용성을 저해하지 않으면서 보안 수준을 높입니다.
  • Confidential Computing을 활용한 OCI 의료 워크로드 제로 트러스트 및 복원력 파이프라인 설계 — 민감한 의료·생명과학 데이터를 보호하기 위해 OCI Confidential Computing 기반의 제로 트러스트 아키텍처를 적용한 파이프라인을 설계했습니다. 데이터는 암호화된 상태로 처리·전송되며, 조직 간 협업 시에도 기밀성을 유지합니다. 또한, 복원력 설계로 장애 발생 시 빠른 복구와 연속성을 보장합니다.

  • PostgreSQL을 OCI로 이전하는 이유 – OCI Database with PostgreSQL 심층 분석 — PostgreSQL을 OCI Database with PostgreSQL 서비스로 마이그레이션하면 패치, 백업, 모니터링, 확장 등 운영 부담을 크게 줄일 수 있습니다. OCI는 자동화된 보안 강화와 고가용성 옵션을 제공해 엔터프라이즈 수준의 안정성을 보장합니다. 또한, OCI 네이티브 스토리지와 네트워킹을 활용해 성능과 비용 효율성을 동시에 달성합니다.
  • OKE 가상 노드, OCI 파일 스토리지 기반 영구 저장소 지원 — OKE Virtual Nodes가 이제 OCI File Storage Service를 백엔드로 하는 쿠버네티스 영구 볼륨(PV)을 지원합니다. 서버리스 방식으로 노드 관리 부담을 줄이면서도 상태ful 워크로드에 필요한 영구 저장소를 제공하므로, 기존에 임시 스토리지에 의존하던 제한을 해소합니다. 설정 과정은 기존 OKE와 동일한 방식으로 진행됩니다.
