OCI Release Notes

2026-09-11 업데이트​

  • Marketplace 고객 인스턴스 보고서의 CSV 내보내기 — OCI Marketplace 고객 인스턴스 보고서에서 대규모 데이터를 CSV로 내보낼 수 있습니다. 필터를 적용한 후 Generate CSV를 선택하면 백그라운드에서 파일이 생성되며, 완료된 최신 내보내기 파일은 최대 24시간 동안 다운로드할 수 있습니다. 또한 많은 고객 인스턴스 데이터를 처리할 때 응답성을 높이기 위해 레코드를 페이지 단위로 불러옵니다.

2026-09-10 업데이트​

  • OCI Generative AI에서 xAI Grok 4.6 사용 — xAI Grok 4.6 모델이 OCI Generative AI에서 온디맨드로 제공됩니다. 코딩, 에이전트 작업, 지식 작업에 최적화되어 있으며, 최대 500,000 토큰의 컨텍스트 윈도우와 장기 에이전트 워크플로우를 지원합니다. 모델 호출 시 사용할 이름은 xai.grok-4.6이며, 우선 처리 옵션이 지원되는 텍스트 API 요청에 적용됩니다. 모델의 기능 및 가격 정책은 Grok 4.6 문서에서 확인할 수 있습니다.

2026-09-09 업데이트​

  • Oracle Cloud Migrations의 AWS EC2 ARM 인스턴스 마이그레이션 지원 — Oracle Cloud Migrations이 ARM 아키텍처를 사용하는 AWS EC2 인스턴스를 OCI Compute로 마이그레이션하는 기능을 추가했습니다. 탐색 단계에서 인스턴스의 아키텍처를 자동으로 파악하고, 마이그레이션 계획에서 해당 아키텍처에 맞는 OCI Compute 형태와 이미지를 추천합니다. 하나의 마이그레이션 프로젝트에 ARM과 x86 기반 자산을 동시에 포함할 수 있으며, 각 자산은 개별적으로 평가되어 적절한 형태가 적용됩니다.
  • OCI Cache 교차 지역 복제 — OCI Cache에 교차 지역 복제 기능이 도입되어 기본 캐시 클러스터의 데이터를 다른 OCI 지역에 있는 보조 클러스터로 비동기 복제할 수 있습니다. 이 기능은 재해 복구를 강화하고, 전 세계 애플리케이션 배포 및 지역 간 워크로드 이동을 지원합니다. 자세한 설정 방법은 교차 지역 복제 가이드를 참고하십시오.

2026-09-07 업데이트​

  • Alibaba Qwen3.8-27B 및 Qwen3.5-397B-A17B 모델 가져오기 — OCI Generative AI에서 Qwen/Qwen3.8-27B와 Qwen/Qwen3.5-397B-A17B 모델을 가져와 엔드포인트를 생성하고 서비스에 사용할 수 있게 되었습니다. 두 모델 모두 TEXT_TO_TEXT 기능을 제공하며, 최소 전용 AI 클러스터 형태는 각각 A100_40G_X2, A100_80G_X1, H100_X1, H200_X1, B200_X1, B300_X1 및 H200_X8, B200_X8 등입니다. 모델 가져오기와 엔드포인트 설정 방법은 Alibaba 모델 가져오기 가이드를 확인하십시오.
  • DeepSeek V4 Pro 0813 모델 가져오기 — OCI Generative AI에서 deepseek-ai/DeepSeek-V4-Pro-0813 모델을 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 이 모델은 TEXT_TO_TEXT 기능을 제공하며, 최소 전용 AI 클러스터 형태는 H200_X8 및 B200_X8입니다. 지원되는 모델 목록과 가져오기 절차는 Models for Import와 DeepSeek 모델 가져오기 가이드를 참고하십시오.
  • Google Gemma 4 31B IT 모델 가져오기 — OCI Generative AI에서 google/gemma-4-31b-it 모델을 가져와 엔드포인트를 생성하고 서비스에 활용할 수 있습니다. 해당 모델은 TEXT_TO_TEXT 기능을 제공하며, 최소 전용 AI 클러스터 형태는 A100_40G_X4, A100_80G_X2, H100_X2, H200_X1, B200_X1 등입니다. 자세한 가져오기 방법은 Google 모델 가져오기 가이드와 Models for Import를 확인하십시오.

2026-09-06 업데이트​

  • OCI Responses API를 이용한 가져온 모델 사용 — OCI Generative AI의 OCI Responses API에서 이제 Alibaba Qwen(Qwen3.6-35B-A3B)과 Google Gemma(gemma-4-31B-it) 모델을 가져와 사용할 수 있습니다. 해당 모델은 Model Import를 통해 지원되며, 온디맨드 서빙 모드에서는 제공되지 않습니다. 모델을 가져온 후 호환되는 전용 AI 클러스터 형태를 선택해 클러스터를 생성하고, 엔드포인트를 설정해야 합니다. 자세한 내용은 Alibaba Qwen 및 Google Gemma 문서를 참고하십시오.

2026-09-04 업데이트​

  • OS Management Hub IPv6 지원 — OS Management Hub가 IPv6 연결을 지원하도록 업데이트되었습니다. OS Management API는 IPv4와 IPv6를 모두 사용할 수 있으며, 기본은 IPv4이지만 IPv6 사용을 위해서는 별도로 활성화해야 합니다. 자세한 설정 방법은 OS Management Hub 문서의 접근 방법 섹션을 참고하시기 바랍니다.

2026-09-03 업데이트​

  • IAM 정책을 통한 OCI Generative AI 모델 접근 제한 — IAM 정책에 target.model.id 조건을 추가하여 그룹이 사용할 수 있는 Generative AI 모델을 제한할 수 있게 되었습니다. 정책에서는 특정 모델 ID를 허용하거나 패턴과 일치하는 ID를 허용하고, 지정된 ID나 패턴을 제외할 수 있습니다. 콘솔에서 모델을 조회하려면 그룹에 inspect generative‑ai‑model 권한을 부여하고, 사용을 제한하려면 use generative‑ai‑family 권한에 target.model.id 조건을 설정합니다. 모델 조회 권한만으로는 모델 호출 권한이 부여되지 않습니다.
  • OCI Monitoring IPv6 지원 — OCI Monitoring API가 듀얼 스택 엔드포인트를 지원하여 IPv6 주소와 IPv4 주소를 모두 반환하도록 변경되었습니다. 이를 통해 IPv6 연결이 가능하면서도 기존 IPv4 호환성을 유지할 수 있습니다. 기존의 IPv4 전용 엔드포인트는 그대로 사용할 수 있습니다. IPv6 사용 방법은 Monitoring 개요 문서의 ‘Ways to Access Monitoring’ 섹션을 참고하시기 바랍니다.
  • Resource Analytics 2026년 9월 업데이트 — Resource Analytics 2026년 9월 릴리즈에서는 Compute, Networking, Bastion, GoldenGate 데이터 모델이 확장되었습니다. Compute 인스턴스의 추가 리소스와 유지보수 이벤트 데이터가 제공되며, Networking에서는 보안 규칙, 서브넷과 보안 리스트 연계, DHCP 옵션 등의 상세 정보가 포함됩니다. 차원‑엔터티 데이터의 최신성을 확인할 수 있는 메트릭이 추가되었고, 각 지원 차원 엔터티별 최신 업데이트 시간을 반환하는 새로운 뷰 ENTITY_LAST_REFRESH_V가 제공됩니다.

2026-09-01 업데이트​

  • 스케줄러 작업 모니터링 및 관리 — Database Management를 통해 Managed Database의 스케줄러 작업을 모니터링하고 관리할 수 있습니다. 작업 목록과 실행 정보를 확인하고, 새로운 작업을 생성하거나 기존 작업을 수정·삭제할 수 있습니다. 현재 프리뷰 모드로 제공되며, 이용 가능 여부는 Oracle Support에 문의하시기 바랍니다.
  • SQL 프로파일 관리 — Managed Database에서 SQL 프로파일을 조회하고, 활성화·비활성화·삭제·카테고리 변경 등의 작업을 수행할 수 있습니다. 이 기능도 현재 프리뷰 모드이며, 이용 가능 여부는 Oracle Support에 문의해 주시기 바랍니다.
  • SQL 방화벽 모니터링 — Security 섹션에 새로운 SQL 방화벽 탭이 추가되어 방화벽 상태, 정책 보호, 최근 활동 등을 한눈에 확인할 수 있습니다. 위반, 캡처, 캡처 로그 및 허용 목록 정보를 모니터링하고 상세 정보를 확인할 수 있습니다. 이 기능은 Oracle Cloud Database 26ai 이상 버전에서 Full Management 옵션이 활성화된 경우에만 제공됩니다.
  • Autonomous AI Database 활동 개요 대시보드 — Oracle이 정의한 Autonomous AI Database 활동 개요 대시보드를 통해 단일 데이터베이스의 활동, 워크로드 및 자원 활용도를 통합적으로 모니터링할 수 있습니다. 주요 메트릭을 한 화면에서 확인함으로써 데이터베이스 운영 상태를 빠르게 파악할 수 있습니다.
  • DBMS_CLOUD.UPDATE_CREDENTIAL로 다중 자격 증명 속성 업데이트 — DBMS_CLOUD.UPDATE_CREDENTIAL를 사용하면 하나의 호출로 여러 자격 증명 속성을 동시에 업데이트할 수 있습니다. OCI 서명 키와 해당 지문처럼 연관된 값을 함께 변경할 때 유용합니다. 자세한 사용법은 UPDATE_CREDENTIAL Procedure에서 확인할 수 있습니다.
  • IoT Flow Runtime 도입 — IoT Flow Runtime은 OCI에서 관리되는 환경으로, 통합 Node‑RED 편집기를 사용해 통합 흐름을 구축·배포·실행할 수 있게 합니다. 흐름 런타임의 수명 주기 관리, 네트워크 접근 설정, 파일 스토리지 마운트 구성 및 관리형 소프트웨어 업데이트가 지원됩니다. Node‑RED 시스템 콘솔 로그는 OCI Logging으로 전송할 수 있습니다.

  • OKE 가상 노드 파일 스토리지 기반 영구 볼륨 지원 — OKE에서 가상 노드에 대해 파일 스토리지 서비스 기반 영구 볼륨을 프로비저닝할 수 있게 되었습니다. 기존에 관리형 노드와 자체 관리형 노드에서 지원하던 기능을 가상 노드에서도 활용할 수 있습니다. 자세한 설정 방법은 Provisioning PVCs on the File Storage Service에서 확인할 수 있습니다.

2026-08-26 업데이트​

  • Enterprise AI NL2SQL 모델 선택 및 백그라운드 SQL 생성 — Enterprise AI NL2SQL은 모델 선택, 예약된 데이터 강화, 백그라운드 SQL 생성 기능을 지원합니다. 모델을 지정하지 않으면 기본값인 openai.gpt-oss-120b가 사용되며, 지역 내에서 사용 가능한 온디맨드 Generative AI 모델을 선택할 수 있습니다. 자세한 내용은 Generative AI Models by Region에서 확인할 수 있습니다.
  • Network Firewall VTAP 소스 지원 — Network Firewall을 Virtual Test Access Point(VTAP) 소스로 선택할 수 있게 되어, 방화벽에 연결된 VNIC의 트래픽 패킷을 캡처하여 모니터링, 문제 해결 및 규정 준수에 활용할 수 있습니다. 캡처된 암호화된 트래픽은 그대로 암호화된 상태로 유지됩니다.
  • Recovery Service 서브넷에 ZPR 보안 속성 추가 — Recovery Service 서브넷에 Zero Trust Packet Routing(ZPR) 보안 속성을 추가하여 최소 권한 모델을 적용할 수 있습니다. 보안 속성은 ZPR 정책에서 참조되어 해당 서브넷에 대한 네트워크 트래픽을 명시적으로 허용된 경우에만 허용합니다. 자세한 내용은 Security attributes와 Managing Security Attributes for Recovery Service Subnet에서 확인할 수 있습니다.

2026-08-25 업데이트​

  • Console AI 체험 프리뷰 확장 — Console AI는 OCI 콘솔 내에서 자연어 기반 대화형 경험을 제공하여 리소스 탐색, 생성, 관리, 문제 해결, 청구 및 사용량 파악 등을 지원합니다. 현재 IAM 권한 범위 내에서 작동하며, 선택된 리전, 컴파트먼트, 리소스 및 권한 정보를 활용합니다.
  • HeatWave 블루/그린 배포 — HeatWave에서 블루/그린 배포를 사용하면 독립형 DB 시스템에 대해 다운타임을 최소화하면서 업그레이드 및 인프라 변경을 수행할 수 있습니다. 먼저 대상(green) DB 시스템을 준비·검증한 뒤, 클라이언트 연결을 기존(blue) 시스템에서 대상 시스템으로 전환합니다. 자세한 내용은 Blue/Green Deployment에서 확인할 수 있습니다.
  • Network Firewall 콘솔 지원 강화 — OCI 콘솔에서 Network Firewall 생성 및 관리 시 방화벽 형태 선택(기본 4 Gbps, 25 Gbps는 테넌시 활성화 시 가능)과 정책 및 하위 리소스에 설명을 추가할 수 있습니다. 매핑된 시크릿을 다중 선택하여 복호화 규칙에 사용할 수 있으며, 방화벽 목록 및 상세 페이지에서 상태와 새로운 메트릭을 확인할 수 있습니다.
  • OCI 유지보수 일정 선택 — OCI 콘솔을 통해 기존 Autonomous AI Database 인스턴스의 유지보수 창을 변경할 수 있습니다. 이를 통해 비즈니스에 가장 적합한 시간대에 유지보수를 수행하도록 조정할 수 있습니다. 자세한 방법은 Change the Maintenance Schedule for an Autonomous AI Database에서 확인할 수 있습니다.
