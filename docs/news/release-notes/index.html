OCI Release Notes

OCI 릴리즈 노트 업데이트를 자동으로 한국어로 정리요약합니다. 원문은 각 항목의 링크에서 확인하세요. 최신 항목이 맨 위에 표시됩니다.

2026-09-29 업데이트​

  • 위젯과 대시보드 필터 연결 간소화
    위젯이 포함된 대시보드에 필터를 추가하면 해당 필터와 일치하는 입력 매개변수를 가진 위젯 목록이 표시됩니다. 위젯은 기본적으로 선택되며 Apply를 클릭하면 필터에 연결됩니다. 연결을 제외할 위젯은 적용 전에 선택 해제할 수 있고, 필터의 Actions 메뉴에서 Edit linked widgets를 선택해 연결 관계를 변경할 수도 있습니다.
  • 연결된 위젯 및 필터 강조 표시
    대시보드 필터와 위젯 간의 연결 관계를 시각적으로 확인할 수 있습니다. 보기 모드에서 필터의 Actions 메뉴에 있는 Highlight dependent widgets and filters를 선택하면 원본 필터는 실선으로, 연결된 위젯과 필터는 점선으로 강조됩니다. 위젯의 Actions 메뉴에서도 Highlight linked filters를 선택해 연결된 필터를 강조할 수 있습니다.
  • 모든 위젯 입력을 로컬 필터로 추가
    위젯 제어판 메뉴에 All inputs 옵션이 추가되었습니다. 이 옵션을 선택하면 사용 가능한 모든 위젯 입력이 로컬 필터로 추가됩니다. 선택을 해제하면 위젯이 기본 구성으로 복원됩니다.
  • 대시보드 필터의 로컬 필터 구성
    Compartment와 같은 대시보드 필터를 개별 위젯의 로컬 필터로도 구성할 수 있습니다. 해당 위젯에서는 로컬 필터 선택이 우선 적용됩니다. 이후 대시보드 필터 선택을 변경하면 대시보드 필터 값이 우선하여 위젯에 적용됩니다.

2026-09-25 업데이트​

  • OCI Generative AI의 xAI Grok 4.7 지원
    xAI Grok 4.7을 OCI Generative AI에서 온디맨드로 사용할 수 있습니다. 코딩, 에이전트 작업, 지식 업무와 중간 결과 확인이 필요한 워크플로를 지원하는 reasoning 모델이며, 500,000토큰의 컨텍스트 창을 제공합니다. 호출 시 모델 이름은 xai.grok-4.7이며, reasoning effort 수준은 low, medium, high(기본값), xhigh 중에서 선택할 수 있습니다.

2026-09-24 업데이트​

  • OCI Functions의 코드 전용 배포
    OCI Functions에서 Go, Java, Node.js 및 Python 관리형 런타임을 위한 코드 전용 배포를 지원합니다. 함수 코드와 종속성을 ZIP 파일로 패키징하거나, 지원되는 Java 함수는 uber JAR로 구성해 컨테이너 이미지를 직접 빌드하거나 관리하지 않고 배포할 수 있습니다. 아카이브를 직접 제공하거나 OCI Object Storage의 파일을 참조할 수 있으며 기존 컨테이너 이미지 배포 방식도 계속 사용할 수 있습니다.
  • HeatWave 자동 스토리지 확장 개선
    현재 할당된 스토리지의 남은 가용 공간이 10% 이하가 되면 DB System 스토리지가 자동으로 확장됩니다. 새 용량은 현재 할당량을 기준으로 계산되며 설정된 최대 스토리지 크기를 초과하지 않습니다.
  • OCI Generative AI의 Z.ai GLM-5.3-Flash 가져오기 지원
    OCI Generative AI에서 zai-org/GLM-5.3-Flash 모델을 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 모델 기능은 IMAGE_TEXT_TO_TEXT이며 최소 전용 AI 클러스터 유닛 Shape은 H100_X8 또는 H200_X4입니다.

2026-09-23 업데이트​

  • OCI Generative AI의 Google Gemma 4 26B A4B IT 가져오기 지원
    OCI Generative AI에서 google/gemma-4-26B-A4B-it 모델을 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 이 모델은 텍스트와 이미지 입력을 지원하고 텍스트를 생성하는 IMAGE_TEXT_TO_TEXT 모델입니다. 최소 지원 Shape에는 A10_X4, A100_40GB_X2, A100_80GB_X1, H100_X1, H200_X1 및 B200_X1이 포함됩니다.
  • OCI Generative AI의 DeepSeek V4.1 Flash 가져오기 지원
    OCI Generative AI에서 deepseek-ai/DeepSeek-V4.1-Flash 모델을 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 이 모델은 텍스트, 이미지 또는 두 형식의 결합 입력을 받아 텍스트를 생성하며 기능 유형은 IMAGE_TEXT_TO_TEXT입니다. 최소 전용 AI 클러스터 유닛 Shape은 H100_X8 또는 H200_X4입니다.
  • Smart Model Router 기반 리전 간 온디맨드 추론 라우팅
    OCI Generative AI의 Smart Model Router를 사용해 사용자가 선택한 리전 범위에서 온디맨드 추론 요청을 교차 리전으로 라우팅할 수 있습니다. 동일 realm 안에서 대상 모델을 제공하는 리전을 선택해 라우팅 프로파일을 만든 후 Chat API 또는 Responses API 요청에서 참조합니다. 요청은 프로파일에 지정된 리전 사이에서만 라우팅됩니다.
  • OCI Generative AI의 리전별 모델 검색
    OCI Generative AI에 지정한 리전에서 사용 가능한 모델을 찾는 model discovery 기능이 추가되었습니다. 모델 기능, 입출력 유형, 온디맨드 또는 전용 제공 여부, temperature와 최대 출력 토큰 등의 매개변수, 종료일을 확인할 수 있습니다. ListModelDiscovery API 작업을 통해 이 기능을 사용할 수 있습니다.
  • Data Science의 Bring Your Own Reservations 지원
    기존 OCI Compute 용량 예약을 Data Science의 notebook session, 단일 노드 job 및 job run, model deployment에 사용할 수 있습니다. Bring Your Own Reservations(BYOR)는 예약을 Data Science로 이전하지 않고 테넌시에 확보된 Compute 용량을 활용합니다. 사용 전 대상 테넌시와 리전에 대한 활성화를 요청해야 하며 지원 Shape, IAM 정책, 서비스 한도 및 예약 용량 조건이 적용됩니다.

2026-09-22 업데이트​

  • Select AI for Java SDK
    Java 애플리케이션에서 Select AI 기능을 사용할 수 있는 Select AI for Java SDK가 제공됩니다. Java 네이티브 API로 AI 프로파일, 자격 증명, 대화, 벡터 인덱스, 자연어 SQL, RAG, 요약, 번역, 피드백 및 합성 데이터 생성을 처리할 수 있습니다.
  • 스키마 간 Select AI Agent Framework 팀 공유 및 실행
    Select AI Agent Framework 팀을 여러 데이터베이스 스키마에서 공유할 수 있습니다. 한 스키마에서 agent 팀을 정의하고 관리한 뒤 다른 사용자나 역할에 소유자 한정 팀 이름으로 실행 권한을 부여할 수 있습니다. 이를 통해 워크플로를 중앙에서 관리하고 여러 사용자에게 일관되게 재사용할 수 있습니다.

2026-09-21 업데이트​

  • Abu Dhabi 온디맨드 모델의 변경된 종료일
    UAE Central(Abu Dhabi) 리전에서 Cohere Command A Vision과 Cohere Embed 4 온디맨드 모델의 종료일이 2026년 10월 12일에서 10월 21일로 변경되었습니다. 종료 후 해당 리전의 온디맨드 추론 호출은 작동하지 않습니다. 다른 리전이나 전용 AI 클러스터에서 제공되는 모델에는 영향을 주지 않습니다.

2026-09-16 업데이트​

  • FastConnect 기능 개선
    FastConnect 파트너, FastConnect Direct 및 Oracle Interconnects의 모든 프라이빗 가상 회로에서 트래픽 드레이닝을 지원합니다. 모든 FastConnect Direct Cross-Connect와 Cross-Connect Group에 최소 링크, 인터페이스 hold-timer 및 Letter of Authorization(LOA) 관련 개선 사항도 적용됩니다.
  • Management Agent 업데이트
    Management Agent에 자체 Jlinked JDK 21이 포함되고 Windows Server 2025 지원이 추가되었습니다. Log Analytics 수집기의 로그 경고 생성 기능이 개선되었으며 버그 및 보안 수정 사항도 반영되었습니다.

2026-09-15 업데이트​

  • DBMS_CLOUD_AI 패키지의 추가 프로파일 속성
    Dedicated Exadata Infrastructure 기반 Autonomous AI Database의 DBMS_CLOUD_AI 패키지에 object_list_mode, enforce_object_list, case_sensitive_values 프로파일 속성이 추가되었습니다. 이를 통해 관련 객체 메타데이터를 자동 식별하고, SQL 생성을 프로파일 객체 목록으로 제한하며, 문자열 값의 대소문자 구분을 제어할 수 있습니다.
  • Oracle Database@Azure의 Azure KMS 기반 Master Encryption Key 관리
    Oracle Database@Azure의 Autonomous AI Database에서 Azure Key Management Service(Azure KMS)를 사용해 Master Encryption Key를 관리할 수 있습니다. 이 기능은 Azure Region의 Dedicated Exadata Infrastructure 기반 Autonomous AI Database에 적용됩니다.
  • OCI Database with PostgreSQL의 고객 관리형 암호화 키 지원
    OCI Database with PostgreSQL에서 사용자가 소유한 암호화 키를 사용할 수 있습니다. 이를 통해 데이터베이스 실행 환경에 적용되는 암호화 키를 직접 제어할 수 있습니다.
  • Java Management Service의 Oracle JDK 27 지원
    Java Management Service에서 2026년 9월 15일 출시된 Oracle JDK 27을 제공합니다. JDK 27은 Java Download와 Java Runtime Lifecycle Management에서 사용할 수 있습니다.
  • Dubai의 Cohere Command A Vision 및 Cohere Embed 4 온디맨드 지원
    UAE East(Dubai) 리전에서 Cohere Command A Vision과 Cohere Embed 4를 온디맨드 방식으로 사용할 수 있습니다. 두 모델 모두 Dubai의 전용 AI 클러스터에서도 제공됩니다.
  • OCI Generative AI의 Z.ai GLM-5.3 가져오기 지원
    UAE Central(Abu Dhabi) 리전의 OCI Generative AI에서 zai-org/GLM-5.3 모델을 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 모델 기능은 TEXT_TO_TEXT이며 필요한 최소 전용 AI 클러스터 유닛 Shape은 B200_X8입니다.- Oracle Database@Azure의 마스터 암호화 키 관리를 위한 Azure KMS 지원 — Oracle Database@Azure의 Autonomous AI Database에서 Azure Key Management Service(Azure KMS)를 사용해 마스터 암호화 키를 관리할 수 있습니다. 이 기능은 Azure 리전의 Dedicated Exadata Infrastructure 기반 Autonomous AI Database에 적용됩니다.

2026-09-14 업데이트​

    UAE Central(Abu Dhabi) 리전에서 Cohere Command A Vision과 Cohere Embed 4의 온디맨드 제공이 사용 중단 단계에 들어갔으며 2026년 10월 21일 종료됩니다. 종료 후 해당 리전에서는 이 모델들에 대한 온디맨드 추론 호출이 작동하지 않습니다. 직접 대체 모델은 없으며 다른 지원 리전의 온디맨드 방식이나 전용 AI 클러스터를 사용할 수 있습니다.

2026-09-11 업데이트​

  • Marketplace 고객 인스턴스 보고서의 CSV 내보내기
    Marketplace의 OCI 고객 인스턴스 보고서에서 필터를 적용한 후 CSV 내보내기를 백그라운드로 생성할 수 있습니다. 완료된 최신 파일은 최대 24시간 동안 다운로드할 수 있습니다. 대량 데이터를 처리할 때 응답성을 높이도록 보고서 레코드도 페이지 단위로 로드됩니다.

2026-09-10 업데이트​

  • OCI Generative AI의 xAI Grok 4.6 온디맨드 지원
    OCI Generative AI에서 xAI Grok 4.6을 온디맨드 방식으로 사용할 수 있습니다. 이 모델은 코딩, agentic 작업, 지식 업무를 지원하며 500,000토큰 컨텍스트 창을 제공합니다. 지원되는 Text API 요청에는 우선 처리를 적용할 수 있으며 모델 이름은 xai.grok-4.6입니다.

2026-09-09 업데이트​

  • OS Management Hub 3.7 및 3.8의 수정 사항과 개선 사항
    OS Management Hub 3.7과 3.8에서 관리 스테이션 상태 및 등록 동기화 문제와 Oracle Linux 8, 9, 10의 Ksplice 업데이트 Job 문제가 수정되었습니다. 예상 백업이 없을 때의 안전한 RPM 데이터베이스 복구와 오래된 YUM 및 DNF 캐시의 자동 정리 기능이 추가되었습니다. Ubuntu 패키지 인벤토리 문제와 반복 그룹 업데이트 Job이 Accepted 상태에 머무는 문제도 해결되었습니다.
  • 구성 가능한 Fault Domain 호스트 균형 조정
    Oracle Cloud VMware Solution이 단일 Availability Domain의 SDDC와 클러스터에서 구성 가능한 Fault Domain 호스트 균형 조정을 지원합니다. 기본적으로 ESXi 호스트는 가용성을 높이기 위해 Fault Domain에 균등하게 분산되며, 필요하면 균형 조정을 비활성화해 가용 용량이 있는 위치에 호스트를 배치할 수 있습니다. 호스트의 Fault Domain 세부정보와 클러스터 균형 상태는 Console과 API에서 확인할 수 있습니다.
  • Oracle Cloud Migrations의 AWS EC2 ARM 마이그레이션 지원
    Oracle Cloud Migrations를 사용해 지원되는 ARM 아키텍처 기반 AWS EC2 인스턴스를 OCI Compute로 마이그레이션할 수 있습니다. 검색 과정에서 원본 인스턴스 아키텍처를 수집하고, 마이그레이션 계획에서 호환되는 OCI Compute Shape와 이미지를 추천하고 필터링합니다. 하나의 프로젝트에 ARM 및 x86 자산을 함께 포함할 수 있으며 각 자산에 적합한 권장 사항과 복제 워크플로가 적용됩니다.
  • OCI Cache의 리전 간 복제
    OCI Cache가 한 리전의 기본 캐시 클러스터에서 다른 리전의 보조 캐시 클러스터로 데이터를 비동기 복제하는 기능을 지원합니다. 이 기능을 통해 재해 복구와 글로벌 애플리케이션 배포를 강화하고 리전 간 계획된 워크로드 이전을 수행할 수 있습니다.

2026-09-07 업데이트​

  • 워크로드 캡처 및 재생을 위한 외부 파일 시스템 지원
    워크로드 캡처와 재생 파일, 보고서를 고객이 관리하는 디렉터리에 저장할 수 있게 되었습니다. 기존의 Object Storage 외에 외부 파일 시스템을 사용할 수 있어 저장 및 관리 유연성이 향상됩니다. 자세한 내용은 Capture and Replay Between Autonomous AI Database Instances에서 확인할 수 있습니다.

2026-08-14 업데이트​

  • OKE 관리 노드 쿠버네티스 버전 롤백 지원
    관리형 노드 풀에서 쿠버네티스 버전을 이전 버전으로 롤백할 수 있게 되었습니다. 롤백하려는 버전이 해당 노드 풀에서 사용 가능하고 컨트롤 플레인 버전과 호환되어야 하며, 롤백 후 기존 관리형 노드를 교체합니다.
  • Google Cloud와 BFD 및 BGP 인증 사용
    Oracle Interconnect for Google Cloud 연결이 Bidirectional Forwarding Detection(BFD)과 BGP MD5 인증을 지원합니다. BFD는 경로 장애 시 몇 초 내에 BGP 업데이트를 트리거해 가용성을 높이고, BGP 인증은 OCI와 Google Cloud 간 라우팅을 안전하게 보호합니다.

2026-08-13 업데이트​

  • OCI Logging IPv6 듀얼 스택 엔드포인트 지원
    OCI Logging의 모든 API가 IPv6와 IPv4를 모두 지원하는 듀얼 스택 엔드포인트를 제공하게 되었습니다. IPv6 사용을 위해 별도 설정이 필요합니다.
  • Search API IPv6 지원
    Search API가 듀얼 스택 엔드포인트를 지원하여 IPv6와 IPv4 중 선택적으로 연결할 수 있습니다. 기존 IPv4 전용 엔드포인트는 그대로 유지되며, 듀얼 스택 엔드포인트는 https://query.<region>.ds.oci.oraclecloud.com 형식을 사용합니다.

2026-08-12 업데이트​

  • Resource Manager 작업 요청 상세 로그 보기 및 다운로드
    Resource Manager에서 지원되는 작업 요청에 대해 상세 로그를 제공하며, 여기에는 드리프트 감지 및 기존 컴파트먼트에서 스택 생성 작업이 포함됩니다. 콘솔에서 로그를 확인·검색·시간표시 숨기기·다운로드할 수 있고, API 또는 CLI를 통해 프로그래밍 방식으로도 접근할 수 있습니다.

2026-08-11 업데이트​

  • OCI 블록 스토리지 랜섬웨어 복구 백업 보호 추가
    OCI 블록 스토리지는 이제 불변 백업(immutable backup)을 지원합니다. 백업은 보존 정책 기간 동안 삭제나 보존 기간 변경이 불가능해져 랜섬웨어 공격에 대한 복구 탄력성을 높이고 규정 준수를 지원합니다.
  • OCI Generative AI, 미국 정부 및 방위 클라우드 제공
    OCI Generative AI 서비스가 미국 정부 클라우드(US Gov West, Phoenix)와 미국 방위 클라우드(US DoD West, Phoenix)에서 이용 가능해졌습니다. 해당 지역에서는 B300 하드웨어 유닛 형태를 사용해 선택된 기본 모델을 호스팅할 수 있으며, 사용을 위해 서비스 제한 증가 요청이 필요합니다.
  • OCI Generative AI에 Moonshot AI Kimi K3 모델 가져오기
    Moonshot AI의 Kimi‑K3 모델을 OCI Generative AI에 가져와 엔드포인트를 생성하고 사용할 수 있습니다. 모델은 IMAGE_TEXT_TO_TEXT 기능을 제공하며, B300_X8, B200_X16, H100_X32 전용 AI 클러스터 유닛 형태가 필요합니다.
  • OCI Generative AI에 NVIDIA Nemotron 3.5 Lightning 모델 가져오기
    NVIDIA Nemotron 3.5 Lightning 모델 두 종류를 OCI Generative AI에 가져와 엔드포인트를 생성할 수 있습니다. 두 모델 모두 TEXT_TO_TEXT 기능을 제공하며, A100_40G_X2, A100_80G_X1, H100_X1, H200_X1, B200_X1 전용 AI 클러스터 유닛 형태가 요구됩니다.
  • Object Storage IPv6 듀얼 스택 엔드포인트 지원
    Object Storage에서 IPv6와 IPv4를 동시에 지원하는 듀얼 스택 엔드포인트를 사용할 수 있게 되었습니다. 듀얼 스택 엔드포인트는 Dedicated Endpoints 형식을 사용하며, 네임스페이스를 호스트명 앞에 포함시켜 IPv6 또는 IPv4 주소로 해석됩니다.
  • Autonomous Container Database(ACD) 전체 백업 스토리지 보기
    Autonomous AI Database on Dedicated Exadata Infrastructure에서 ACD 전체 백업 용량이 상세 페이지에 계산되어 표시됩니다. 이를 통해 백업 스토리지 사용량을 한눈에 확인할 수 있습니다.
  • Apache Iceberg 테이블 타임 트래블
    Apache Iceberg 외부 테이블을 지정된 시점의 상태로 조회할 수 있도록 Oracle SQL의 AS OF TIMESTAMP 구문이 지원됩니다. 이를 통해 과거 데이터에 대한 분석, 감사, 문제 해결 및 재현 가능한 보고서를 작성할 수 있습니다.
  • Select AI 에이전트 팀 가져오기·내보내기
    Autonomous AI Database에서 DBMS_CLOUD_AI_AGENT.IMPORT_TEAM 및 DBMS_CLOUD_AI_AGENT.EXPORT_TEAM API를 이용해 Select AI 에이전트 팀 정의를 JSON, Object Storage 파일 또는 디렉터리 파일 형태로 가져오고 내보낼 수 있습니다. 이 기능은 마이그레이션, 백업, 버전 관리 및 팀 공유를 간소화합니다.
  • DBMS_CLOUD 패키지 GET_DEFINITION 함수
    GET_DEFINITION 함수는 DBMS_CLOUD_AI, DBMS_CLOUD_AI_AGENT, DBMS_CLOUD_PIPELINE, DBMS_CLOUD 패키지로 생성된 객체의 실행 가능한 PL/SQL 정의를 반환합니다. 이를 활용해 객체 정의를 검사, 내보내기, 비교 및 재생성할 수 있습니다.

2026-08-10 업데이트​

    OKE 클러스터 애드온에 새로운 버전이 제공됩니다. WebLogic Kubernetes Operator는 v4.3.10, Istio는 v1.29.5, Native Ingress Controller는 v1.4.5으로 업데이트되었습니다.
