Oracle Developers Medium 블로그

Oracle Developers Medium 블로그 업데이트를 자동으로 한국어로 정리요약합니다. 원문은 각 항목의 링크에서 확인하세요. 최신 항목이 맨 위에 표시됩니다.

2026-10-02 업데이트​

  • Oracle AI Agent Memory를 위한 그래프 인식 검색과 시간축 메모리 연결
    그래프 인식 검색을 통해 Oracle AI Agent Memory가 각 메모리를 독립된 기록으로 처리하지 않고 시간에 따른 사실의 변화를 파악할 수 있습니다. supersedes, refines, supports, duplicates, contradicts와 같은 유형화된 링크로 메모리 간 관계를 명시해 장기 실행 에이전트의 맥락 이해를 개선합니다. 동반 Graph-Aware Retrieval for AI Agent Memory 노트북은 이러한 검색 방식의 구현 예제를 제공합니다.

2026-09-28 업데이트​

  • Oracle AI Agent Memory의 그래프 인식 검색, 이미지 메모리 및 엔터프라이즈 제어
    Oracle AI Agent Memory에 그래프 인식 검색, 이미지 인식 메모리, 스키마 업그레이드 지원 및 엔터프라이즈 제어 기능이 추가되었습니다. 메모리는 생성, 연결, 갱신, 대체, 검색 및 거버넌스의 명시적인 수명 주기로 관리됩니다. Graph Memory는 형식이 지정된 관계로 메모리를 연결하고, 검색 시 직접 일치한 정보뿐 아니라 연관된 문맥도 함께 반환합니다.
  • Amazon S3와 AWS Secrets Manager를 활용한 python-oracledb의 Oracle AI Database 26ai 연결
    Oracle AI Database 26ai 연결 설정을 Amazon S3와 AWS Secrets Manager에 중앙화하고 python-oracledb 26.0.0에서 단일 DSN으로 연결하는 방식을 소개합니다. Centralized Configuration Provider를 사용하면 자격 증명을 코드에 넣지 않고 연결 정보가 코드, 환경 변수, 배포 스크립트에 분산되는 문제를 줄일 수 있습니다. 애플리케이션은 관리형 위치에서 설정과 비밀 정보를 가져와 데이터베이스 연결을 구성합니다.
  • Oracle과 DeepLearning.AI의 AI 개발자용 Agent Memory 과정 출시
    Oracle과 DeepLearning.AI가 AI 개발자와 엔지니어를 위한 무료 단기 과정인 Agent Memory: Building Memory-Aware Agents를 출시했습니다. 이 과정은 프롬프트 및 컨텍스트 엔지니어링을 넘어 에이전트가 장기간 정보를 유지하고 활용하도록 설계하는 메모리 엔지니어링을 다룹니다. Oracle AI Database를 에이전트 메모리의 핵심 저장소로 사용해 적응형 에이전트를 구성합니다.
  • Jev와 Oracle AI Database를 활용한 에이전트 메모리 거버넌스
    System One 모델인 Jev와 Oracle AI Database를 사용해 에이전트가 관련 근거를 선택하고 장기 메모리에 보존할 정보를 결정하는 방식을 설명합니다. 메모리의 단순 저장보다 관련성 평가와 보존 정책을 적용해 검색 품질과 메모리 거버넌스를 높이는 데 초점을 둡니다. 모든 예제는 Oracle AI Database 26ai와 Jev를 사용하는 Oracle Jev Memory 노트북으로 제공됩니다.

2026-09-23 업데이트​

  • Karpenter를 활용한 OKE 워크로드 인식형 자동 확장
    Karpenter Provider OCI를 사용해 OKE에서 워크로드 요구에 맞는 노드를 자동 프로비저닝하는 방법을 소개합니다. NodePool과 OCINodeClass로 스케줄링 및 OCI 인프라 동작을 정의하고, 선점형 인스턴스와 온디맨드 인스턴스의 가중치를 조정해 비용과 대체 용량을 함께 관리합니다. 정적 NodePool도 지원하며 OCI shape, 이미지, 네트워킹, 용량 유형과 통합됩니다.

2026-09-21 업데이트​

  • 멀티모델 데이터베이스의 가치
    관계형, JSON, 벡터, 텍스트, 그래프, 공간 데이터를 하나의 데이터베이스에서 함께 조회하고 갱신하는 멀티모델 접근 방식을 소개합니다. 관련 데이터를 함께 관리하면 하이브리드 검색과 트랜잭션 일관성을 구현하면서 시스템 간 데이터 이동을 줄일 수 있습니다. 벡터, JSON, 이벤트 스트리밍을 결합한 예제는 동반 노트북으로 제공됩니다.
  • Oracle SQLcl MCP Server와 Oracle AI Database를 활용한 Antigravity 워크플로 구축
    Antigravity와 Oracle AI Database를 연결하는 MCP 기반 워크플로 패턴을 설명합니다. MCP는 AI의 데이터베이스 접근을 암묵적인 시스템 권한이 아니라 명시적인 도구 계약으로 정의하며, Oracle SQLcl은 MCP Server 모드에서 데이터베이스 작업을 도구로 제공합니다. 실행 가능한 흐름은 Antigravity MCP with Oracle AI Database Workflow 노트북에 구현되어 있습니다.

2026-09-10 업데이트​

  • API 키 없이 Jenkins에서 OCI 호출
    OCI 외부에서 실행되는 Jenkins가 영구 OCI API 서명 키를 저장하지 않고 OCI를 호출하는 방법을 설명합니다. Jenkins의 단기 OIDC 빌드 토큰을 단기 OCI 세션 토큰으로 교환하며, OCI Identity Propagation Trust가 토큰을 검증하고 빌드를 OCI 서비스 사용자에 매핑합니다. 실제 접근 권한은 OCI IAM 정책으로 제어되며, Jenkins의 고정 서명 키와 빌드별 임시 키는 서로 다른 역할을 수행합니다.

2026-09-09 업데이트​

  • 프로덕션 환경을 견디는 에이전트 하네스 구축
    에이전트가 작업 완료를 잘못 보고하거나 외부 API 호출에 실패하는 상황을 방지하기 위한 프로덕션 하네스 설계를 다룹니다. 모델은 작업을 제안하고 하네스는 권한과 정책을 검증하며, 실제 환경은 승인된 변경만 적용하도록 역할을 분리합니다. 실행 결과를 모델의 서술이 아닌 외부 시스템의 상태로 검증하는 구조가 중요합니다.

2026-09-08 업데이트​

  • Oracle AI Database와 Java MCP Toolkit을 활용한 A2UI 및 MCP Apps 개발
    Oracle AI Database와 Java MCP Toolkit을 기반으로 Google Gemini Enterprise App, ChatGPT, Claude에서 실행되는 에이전틱 AI 애플리케이션의 풀스택 패턴을 소개합니다. Java MCP Toolkit은 백엔드 도구를, A2A는 에이전트 간 또는 호스트와 에이전트 간 통신을, A2UI와 MCP Apps는 프런트엔드 상호작용을 담당합니다. 렌더링·상호작용·실행 경계를 명확히 분리해 신뢰할 수 있는 네이티브 UI와 샌드박스형 이식 가능 앱을 구성합니다.

2026-09-04 업데이트​

  • Oracle Select AI를 활용한 주식 영상 semantic search 여정 Oracle AI Database 26ai, Oracle Select AI, vector search와 RAG를 결합해 주식 관련 영상 콘텐츠를 의미 기반으로 분석한 사례입니다. Select AI를 이용하면 자연어로 질문하면서 SHOWSQL로 생성된 SQL을 확인하고 실행 전에 검증할 수 있습니다. vector embedding을 활용해 단순 키워드 집계를 넘어 특정 주식의 위험과 기회처럼 의미 중심의 질문을 처리합니다.

2026-09-02 업데이트​

  • Oracle AI Database 기반 통제형 Cursor MCP workflow
    Cursor CLI와 Oracle AI Database를 결합해 AI assistant의 데이터베이스 접근을 통제하고 검사하며 반복 실행할 수 있는 MCP workflow를 제시합니다. MCP는 AI가 시스템에 암묵적으로 접근하는 대신 명시적인 도구 계약을 통해 데이터베이스 기능을 호출하도록 합니다. 이를 통해 실행 권한과 호출 과정을 명확히 관리할 수 있습니다.
  • LangChain.js용 langchain-oracledb 통합 패키지
    Oracle AI Database와 LangChain.js를 연결하는 @oracle/langchain-oracledb 1.0 패키지가 npm에 공개됐습니다. TypeScript와 JavaScript 애플리케이션에서 Oracle AI Database 26ai의 vector search 기능을 사용할 수 있습니다. 문서 수집, 검색 증강 생성(RAG), AI workflow 구축에 필요한 핵심 통합 기능을 제공합니다.

2026-08-28 업데이트​

  • Oracle AI Database용 신규 Thin Go 드라이버
    Oracle이 Oracle AI Database용 공식 순수 Go 드라이버 go-oracledb를 공개했습니다. 이 드라이버는 Go의 표준 database/sql 인터페이스를 구현하며 Oracle AI Database 19c 이상과 TCP 또는 TCPS로 연결됩니다. CGO와 Oracle Client 라이브러리가 필요하지 않아 빌드 의존성을 줄이고 컨테이너 재현성과 크로스 플랫폼 배포를 단순화합니다.
  • 적응형 AI agent 구축 신규 단기 과정
    Oracle과 DeepLearning.AI가 AI agent의 지속적·적응형 학습을 다루는 단기 과정 Building Adaptive AI Agents를 공개했습니다. 이 과정은 시간이 지남에 따라 agent를 개선하는 여러 방식과 Oracle AI Database 26ai에서 이를 구현하는 방법을 설명합니다. agent의 기억과 피드백을 활용해 동작을 점진적으로 개선하는 설계가 핵심입니다.
  • Autonomous Database용 python-oracledb Thin·Thick 연결 모드 비교
    python-oracledb의 Thin 모드는 별도의 클라이언트 설치 없이 순수 Python으로 동작하지만, Thick 모드는 실행 환경에 Oracle Instant Client가 필요합니다. wallet을 사용하는 Autonomous Database 연결에서도 모드별 설정 방식이 다릅니다. 특히 Thin 모드에서는 데이터베이스 암호와 wallet 인증서 파일을 해제하는 wallet_password를 구분해야 합니다.

2026-08-24 업데이트​

  • AI agent의 운영 데이터베이스 접근에서 얻은 교훈
    Oracle은 AI agent가 기업 데이터를 안전하게 조회하고 Oracle AI Database를 영구 메모리로 활용하는 방식을 소개합니다. agent가 직접 SQL을 생성하도록 두는 대신, 데이터 접근을 통제된 도구와 명확한 권한 경계로 제한하는 접근법을 다룹니다. 운영 환경에서는 편의성뿐 아니라 권한 관리, 동작 검증, 감사 가능성을 함께 고려해야 합니다.
