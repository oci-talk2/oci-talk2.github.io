OCI 블로그 업데이트를 자동으로 한국어로 정리요약합니다. 원문은 각 항목의 링크에서 확인하세요. 최신 항목이 맨 위에 표시됩니다.

2026-10-02 업데이트​

  • 중복 IP 주소 문제 해결을 위한 DRG NAT 도입
    OCI DRG에 IPv4 주소 공간이 중복되는 네트워크 간 프라이빗 연결을 지원하는 Network Address Translation(NAT) 기능이 도입됐습니다. IP 주소를 다시 할당하거나 별도 NAT 어플라이언스를 배포하지 않고 네트워크를 연결할 수 있습니다. 이 기능은 모든 상용 OCI 리전에서 추가 비용 없이 제공됩니다.
  • Oracle AI Data Platform 기반 AI 지원 민감 데이터 거버넌스 프레임워크 구축
    Oracle AI Data Platform(AIDP)을 기반으로 엔터프라이즈 데이터셋에 숨겨진 민감 정보를 식별하고 적절한 보호 및 접근 제어를 지원하는 맞춤형 프레임워크를 구축할 수 있습니다. 데이터, 스키마, 사용자 역할이 변경될 때 기존 제어와 조직 정책 간의 불일치를 줄이고 민감 데이터 거버넌스의 수작업 부담을 완화합니다.

2026-10-01 업데이트​

  • Project Conexus: 연결된 국방 작전을 위한 협업 접근 방식
    Project Conexus는 기존 지휘통제 시스템, 통신 네트워크, 임무 애플리케이션을 통합해 복잡한 연합 작전 환경에서 더 빠르고 정확한 의사결정을 지원하는 접근 방식입니다. 단일 기업이 아닌 여러 기술 제공업체의 생태계와 협업을 통해 국방 조직의 현대화를 추진합니다.

2026-09-29 업데이트​

  • OCI 기반 네이티브 ONTAP 스토리지, OCI NetApp Storage Service
    OCI에 NetApp ONTAP 기능을 네이티브로 제공하는 OCI NetApp Storage Service가 소개되었습니다. 기업은 기존 ONTAP 기반 데이터 인프라의 운영 일관성과 스토리지 기능을 유지하면서 워크로드와 데이터를 OCI로 이전할 수 있습니다. 높은 가용성과 성능이 필요한 엔터프라이즈 워크로드를 지원하도록 설계되었습니다.
  • OCI IAM Identity Assurance 신호를 활용한 위험 인사이트 도출
    원격 근무와 인공지능의 확산으로 자격 증명 탈취를 넘어 실제 직원을 사칭하는 공격 위험이 커지고 있습니다. OCI IAM의 Identity Assurance 신호를 활용하면 사용자 신원과 인증 활동을 분석해 잠재적인 사칭 및 계정 위험을 식별하는 데 필요한 인사이트를 얻을 수 있습니다.
  • OCI Functions 코드 전용 배포 정식 출시
    OCI Functions에서 Go, Java, Node.js, Python 관리형 런타임을 위한 코드 전용 배포 기능이 정식 출시되었습니다. 함수 코드와 종속성을 아카이브로 패키징하고 런타임을 선택하면 컨테이너 이미지를 직접 빌드하거나 관리하지 않고 함수를 생성할 수 있습니다. 런타임 환경은 OCI Functions가 관리합니다.
